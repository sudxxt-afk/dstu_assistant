# DSTU Assistant — Design System

Система «Кампус» (v3, палитра Anthropic) для личного инструмента (расписание/задачи/лекции).
Светлая и тёмная темы по настройке системы. Рабочая панель: чисто, читаемо,
с характером, без декора ради декора.

## Принципы

1. **Токены — единственный источник правды.** Любой цвет/размер/отступ берётся из
   переменной (`src/styles/tokens.css`). Хардкод-значений в компонентах нет.
2. **Один акцент — терракота (Crail).** Текущая пара (рамка), активная навигация,
   фокус, первичное действие. Нейтрали тёплые: Ivory `#faf9f5`, Dark `#141413`,
   Mid Gray `#b0aea5`. Типы пар: лекция — терракота, практика — зелёный,
   лаба — синий, семинар — серый.
3. **Плоско, бумажно.** Слои `canvas` → `surface` → `sunken`, hairline-границы,
   без градиентов, свечения и теней у карточек. Тень только у оверлеев.
4. **Консистентность важнее креатива.** Компонент переиспользуется, а не рисуется
   заново. Нет компонента — см. «паттерны» или заводим новый по этому же языку.
5. **Что не задокументировано — не существует.** Этот файл + токены = контракт.

## Слои стилей

```
styles.css            → агрегатор (@import)
 ├ styles/tokens.css      основы (цвет, типо, отступы, радиусы, движение, z, layout)
 ├ styles/base.css        сброс, дефолты элементов, типо-утилиты (.t-*)
 └ styles/components.css   примитивы (.btn, .field, .card, .badge, .segmented, …)
```

## Токены

### Цвет (роли)
| Токен | Назначение |
|-------|-----------|
| `--color-canvas` | фон приложения |
| `--color-surface` / `--color-surface-hover` | карточки, строки, поля / ховер |
| `--color-raised` | оверлеи, диалоги |
| `--color-sunken` | утопленные зоны: трек сегментов, колонки недели |
| `--type-lecture/-practice/-lab/-seminar` | цвет типа пары |
| `--color-border-subtle/-/-strong` | границы по возрастанию контраста |
| `--color-text` / `-secondary` / `-tertiary` / `-disabled` | текст по иерархии |
| `--color-accent` / `-hover` / `-soft` / `-border` | акцент (циан) и его состояния |
| `--color-on-accent` | текст на акцентной заливке |
| `--color-danger` / `-soft`, `--color-warning`, `--color-success` | статусы |
| `--color-focus-ring` | кольцо фокуса |

### Типографика
Шрифты: `--font-display` (Lora, serif — заголовки, бренд, номер недели), `--font-sans` (Onest — текст), `--font-mono` (JetBrains Mono — время,
аудитории, числа).

Шкала (база 15px): `--text-2xs` 11 · `--text-xs` 12 · `--text-sm` 13 ·
`--text-base` 15 · `--text-md` 16 · `--text-lg` 18 · `--text-xl` 24 ·
`--text-2xl` 32 · `--text-3xl` 40.
Веса: `--weight-regular/medium/semibold/bold`.

Роли (утилиты): `.t-display` · `.t-h1` · `.t-h2` · `.t-title` · `.t-body` ·
`.t-label` · `.t-meta` · `.t-eyebrow` · `.t-caption`. Текстовые утилиты: `.mono` `.muted` `.dim`.

### Отступы — сетка 4px
`--space-1` 4 · `-2` 8 · `-3` 12 · `-4` 16 · `-5` 20 · `-6` 24 · `-8` 32 · `-10` 40.
Произвольные значения вне шкалы не используем.

### Прочее
Радиусы `--radius-sm` 6 · `-md` 10 · `-lg` 12 · `-full` · границы `--border-hairline` · тень
`--shadow-overlay` · движение `--dur-fast/med` + `--ease-standard/out` ·
слои `--z-nav/overlay/toast` · layout `--sidebar-w` `--content-max` `--page-pad`.

## Компоненты

### Button — `.btn`
| Вариант | Класс | Когда |
|---------|-------|-------|
| Secondary | `.btn` | обычное действие |
| Primary | `.btn-primary` | главное действие экрана |
| Ghost | `.btn-ghost` | третичное, без рамки |
| Danger | `.btn-danger` | деструктивное |

Размеры: `.btn` (34px), `.btn-sm` (28px). Состояния: `:hover` `:active` `:disabled`
(opacity .5, не кликается) `.is-loading` (спиннер, блокировка).

### Icon button — `.icon-btn`
Квадратная кнопка с иконкой. `.sm` (24px), `.danger` (ховер в красный). Для
стрелок навигации, edit/delete в строках.

### Field — `.field`
`label` + control. Элементы `input/select/textarea` стилизованы глобально.
Состояния: `:focus` (акцентная рамка + кольцо), `[aria-invalid="true"]` (красная
рамка), `:disabled` (opacity .5). У `select` своя стрелка.

### Card — `.card`
Поверхность + граница + радиус. Паддинги задаёт родитель токенами отступов.

### Badge — `.badge`
Пилюля со статусом (перенос, неделя, срок). Варианты: `.badge` (акцент),
`.badge-danger`, `.badge-muted`.

### Type pill — `.type-pill`
Тип пары капслоком цвета типа, без заливки: `.is-lecture` `.is-practice` `.is-lab` `.is-seminar`.

### Chip — `.chip`
День в полосе недели: `.is-active` (тёмная заливка), `.is-today` (контур).

### Segmented — `.segmented`
Переключатель из сегментов (`> button`, активный — `.is-active`). Используется
для День/Неделя.

### Checkbox — `.checkbox`
Круг со статусом `.is-checked` (акцентная заливка + галка).

### Empty — `.empty`
Пустое состояние: пунктирная рамка, `<strong>` заголовок + подсказка.

## Паттерны

- **App shell** — сайдбар с логотипом и карточкой недели (десктоп ≥760px) /
  плавающая нижняя навигация (мобила <760px), активный пункт — мягкая акцентная заливка. Контент: `--content-max`, паддинг `--page-pad`.
- **Page header** — `.t-h1`/`.t-display` слева, действия справа, flex-строка.
- **Form grid** — поля в `.grid` (2–3 колонки, 1 на мобиле), `.col2` на всю ширину.
- **Lesson card** — `время | название + type-pill + препод | аудитория + №`.
  Текущая пара — акцентная рамка, подпись «Идёт сейчас» и полоса прогресса.
- **Task row** — карточка `чекбокс | название | срок | удалить`; просроченный срок — `.badge-danger`.

## Адаптив
Один брейкпоинт: **760px**. Ниже — одна колонка, нижняя навигация, поля во всю
ширину. Учитываются `env(safe-area-inset-*)` (вырез/жесты).

## Доступность
- Фокус клавиатурой всегда виден (`:focus-visible`), мышью — нет.
- Обе темы проверены на контраст текста и акцента; тип пары дублируется подписью,
  не только цветом.
- `prefers-reduced-motion` отключает анимации.

## Как расширять
Новый визуальный примитив → сначала проверь существующие компоненты; если нужен
новый — опиши вариант/состояния здесь и реализуй в `components.css` на токенах.
Новых «магических» px/hex в `.vue` не заводим.
